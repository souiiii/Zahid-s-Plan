# Phase 1 resource pool — 26 October–4 November 2026

This pool inherits [ROADMAP.md](../../ROADMAP.md): **Continuity and Differentiability, Current Electricity, Solutions, and the organic foundation needed for Class 12**. It contains resources and precise practice selections. Daily slots and the `.ics` file come later. English, Hindi and Hinglish are all acceptable.

**Start with this file.** Use [practice-index.md](practice-index.md) for exact questions. [pool.json](pool.json) records stable resource IDs, topic units, source locations, selected questions and estimates so later calendar slots can inherit the same choices without searching again.

**Quality and time rules**

- NCERT and original board papers are the anchors. Videos explain the selected material; every learning topic leads to independent book or board-question practice.
- One main video per subject/track. No second full lecture, long channel playlist, paid course or separate commercial question bank is required.
- Selected NCERT questions cover different methods and reasoning types. Additional in-syllabus questions remain available if weaknesses appear; unselected does not mean unexaminable.
- Attempt before checking, including when a video presents a problem. Correct errors and reattempt them before accumulating more questions.
- Read current CBSE scope before following an older video's extras. Skip explicitly excluded material and unnecessary entrance-exam extensions. “Sure shot”, view counts and score promises are not evidence of exam coverage.

**What has been verified:** the four public video identities, creators, actual runtimes and returned playability status; teacher descriptions; correspondence with NCERT chapter scope; local book/exercise locators; selected board-question numbers; and the provenance of current official sample papers and marking schemes. The selected chemistry PYQs were checked visually because their scanned pages do not extract properly as text. Full videos have **not** been watched end to end, so these are screened learning aids, not a claim that every explanation in 14½ hours has been independently audited. The strongest content-quality verification is for the NCERT and official assessment material.
